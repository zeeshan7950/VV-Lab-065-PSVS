# Change Request (CR)

| Field | Entry |
|---|---|
| **CR ID** | CR-YYYY-NNN |
| **Artifact** | Name, ID and version affected (e.g. PSVS-REQ-v1.0, S7) |
| **Date / Requested by** | |
| **Reason** | Defect ID(s) or need driving the change (e.g. D18 - S7 vs S8 contradiction) |
| **Proposed change** | Exact old text -> new text |
| **Impact** | Other requirements, models, proofs, tests affected; effort; risk |
| **Alternatives considered** | |
| **Approver** | Name / role |
| **Decision** | Approved / Rejected / Deferred - date - signature |
| **Resulting baseline** | e.g. PSVS-REQ-v1.1, tag baseline-2 |
